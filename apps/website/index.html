How it works, honestly

Nothing to hide, so here is exactly what happens.

CouchTube is a tiny messenger between your phone and your browser. It sends button presses one way and "what's playing" the other way. That's the whole product.

Your computer

The extension runs on youtube.com only and presses the same buttons you would.

⟷play · pause · seek
volume · search text
title of the video

The relay

A small server that forwards messages between the two, like a walkie-talkie channel. It stores nothing.

⟷the same messages
nothing else

Your phone

A plain web page with big buttons. Nothing is installed and nothing is remembered.

What goes through the relay

  • Commands: play, pause, +10 s, volume 60%, speed 1.5×
  • Text you type in the search box on the phone
  • The title, channel and progress of the video that is playing
  • The list of suggested videos, so you can pick one

What never leaves your computer

  • Your Google or YouTube account, cookies or passwords
  • The video or audio itself (it plays on your computer, as always)
  • Your watch history, your other tabs, anything outside youtube.com
  • Nothing is written to a database. The relay has none.

A code only your screen can show

Each session gets a random code. It lives in the QR on your monitor, so only someone who can see your screen can pair. Click "New code" and every old code dies instantly.

Open source, read every line

The extension, the relay and the phone page are all on GitHub under the MIT license. No build step, no minified blobs: what you read is what runs.

Only on youtube.com, only while you use it

The extension asks for permission to run on youtube.com and nothing else. Pause it from the popup, or remove it in one click, whenever you like. Prefer full control? Run your own relay with one command.

Questions people ask

FAQ

Is this safe? What can the extension see?

It can see and act on youtube.com tabs, nothing else: that is the only permission it asks for. It never reads your Google account, cookies or passwords, and the relay server has no database. All the code is public on GitHub, so you (or a developer you trust) can verify every line.

Do I need to install an app on my phone?

No. Scanning the QR code opens a normal web page in your phone's browser. It works on iPhone and Android, and you can add it to your home screen if you want a shortcut.

Does the phone need to be on the same Wi-Fi?

No. Messages go through the relay, so mobile data works too. Only the screen matters: whoever can scan the code can control that browser.

Can someone else control my YouTube?

Only if they scan the code on your screen. Codes are random, unguessable, and you can click "New code" in the popup at any time to cut off every connected phone.

Does it work with ads, Premium, live streams, playlists?

Yes. Ads show a Skip button on your phone when YouTube offers one. Live streams get a "Jump to live" button. Playlists show up in "Up next".

Will it slow down YouTube or my computer?

No. It is a few small scripts that only run on youtube.com and send a tiny message about once per second while a video plays.

Firefox? Safari? Edge?

Edge and Brave work today, since they run Chrome extensions. Firefox is planned. Safari is not, for now.

Can I run my own relay?

Yes. The relay is a single Node.js file. Run it, point the extension at it in the popup's settings, and nothing ever touches our server.

Is CouchTube affiliated with YouTube or Google?

No. It is an independent, open-source project. YouTube is a trademark of Google LLC.
